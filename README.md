# Calculator

A fully responsive, interactive calculator built with clean code and modern web standards.

## ✨ Features
* **Fully Responsive:** Works perfectly on desktops, tablets, and smartphones.
* **Keyboard Support:** Use your physical numpad or number keys to perform calculations.
* **Paste Support:** Paste mathematical strings directly into the calculator.
* **Clean UI:** Minimalist design inspired by modern mobile OS calculators.

## 🛠️ Built With
* **HTML5:** Semantic structure.
* **CSS3:** Grid and Flexbox for the layout.
* **JavaScript:** JS for logic (no frameworks).

## 🚀 How to Use
1. Clone the repository.
2. Open `index.html` in any browser.
3. Start calculating!
